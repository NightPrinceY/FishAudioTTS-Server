We tried running the Fish Audio S2-Pro TTS server. The model loads successfully, but inference fails due to GPU issues. Initially we had CUDA out-of-memory errors, and later a PyTorch CUDA allocator crash (CUDACachingAllocator.cpp INTERNAL ASSERT FAILED). The root cause is the current dual-GPU setup (cuda:0 for model and cuda:1 for codec), which is unstable for this model. The fix is to run both model and codec on the same GPU (preferably a free one like cuda:4) and reduce max_seq_len in KV cache (4096 → 1024 or 2048). After that, restart the server and test again with a small request.
